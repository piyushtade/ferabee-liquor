### Site Selection Criteria Matrix (Minimum Store Viability Benchmark)
1. **Footfall & Traffic Index:** Located on major arterial roads or high-density food & beverage hubs with daily footfall >15,000 pedestrians/vehicles.

3. **Demographic Catchment:** Minimum population of 100,000 within 5 km radius, with >35% falling in the 21–45 age demographic.

## PILLAR 2: State Excise, Inter-State Duty & Regulatory Compliance

Inter-state movement of liquor between Goa (Manufacturing base) and Maharashtra (Primary consumption market) requires rigorous compliance with state excise tariffs and transit permit laws.

```
+-------------------------------------------------------------------------------+
| STATE EXCISE DUTY & TRANSIT WORKFLOW MATRIX                                   |
+-------------------------------------------------------------------------------+
| STAGE                 | STATUTORY PROCEDURE & REGULATORY COMPLIANCE           |
|-----------------------+-------------------------------------------------------|
| 1. Distillery Clearance| Bottling permit issued via Goa Excise Portal (GEMS)   |
|                       | Payment of Goa Export Duty (~₹10-₹15 per case).       |
|                       |                                                       |
| 2. Transit Pass (TP)  | Application for Inter-State Transport Pass (Pass-2). |
|                       | GPS-tracked bonded truck dispatch from Goa facility.  |
|                       |                                                       |
| 3. Maharashtra Entry  | Import Pass verification at Maharashtra State Border  |
|                       | Excise Checkposts (e.g., Banda / Insuli checkpost).   |
|                       | Payment of Maharashtra Special Excise Duty & Pass Fee. |
|                       |                                                       |
| 4. Bonded Warehouse   | Stock deposited in State-approved FL-1 Wholesale      |
|                       | Bonded Warehouse before distribution to FeraBee bars. |
+-------------------------------------------------------------------------------+
```

### Legal "Prix-Fixe" Formatting (Avoiding Promotional Drinking Violations)
State Excise Laws prohibit promoting "unlimited alcohol consumption" or "free drinking competition". FeraBee operates under a 100% legal **Prix-Fixe Culinary Experience** framework:
* **Legal Board Wording:** Listed on menus and promotional boards as: *"Prix-Fixe Gourmet Dining Experience with Complimentary FeraBee Tasting Session"*.
* **Terms of Service:** Maximum of 6 pegs (60ml each) of hard spirits or unlimited beer within a strict 2.5-hour seating window, enforced via wristband tracking.
